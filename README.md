
# Flying Boat Mod

A mod that adds an ability to fly to A Short Hike boats. Press F to make your boat fly.


## Set up and configuration
### Melon Loader
**Install**\
Recommended version: v0.5.7\
Other versions might also work but are still untested.\
Download the [latest version of the mod](https://github.com/Lotli/AShortHike_FlyingBoat/releases/latest) and put it in the Mods folder.\
